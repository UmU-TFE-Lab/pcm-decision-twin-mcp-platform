# PCM dataset release v1.0.0

`pcm_thermal_storage.csv` is released as a frozen, checksum-identified constructed
scenario dataset. The BuildingEnvelope interpretation has author-reported pilot and
IDA-ICE context; SolarTES, BatteryCooling, and HVACStorage are scenario extensions.
The table passes documented internal constraints, but it is not an all-variable
measurement table or an independently validated operational record.

The exact original row-generation program is unavailable and is not distributed. This
release therefore does not claim that a newly written generator can recreate the CSV
byte for byte. Reproducibility for v1.0.0 is provided through:

- the canonical CSV and SHA-256 digest;
- `field_dictionary.csv`;
- `generator_config.yaml`, which records the documented scenario envelope;
- `dataset_schema.json`;
- `scripts/validate_dataset.mjs`, which verifies structure, ranges, branch counts, and
  physics-consistency checks;
- `dataset_manifest.json`, generated by the validation script.

A future dataset v2 must use an executable generator from the outset and rerun all
software validation and MCP benchmark procedures. It must not silently replace v1.0.0.
